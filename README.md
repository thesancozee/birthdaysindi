# Starlight Birthday Website

Website ulang tahun yang cukup menggunakan satu file utama, `index.html`. CSS dan JavaScript sudah digabung ke dalam file tersebut.

## Struktur
- `index.html` — seluruh kode website (HTML, CSS, dan JavaScript).
- `assets/photos/` — foto `photo-01.jpg` sampai `photo-16.jpg`.
- `assets/music/tunggal-eka.mp3` — backsound.

## Mengganti foto
Ganti foto di `assets/photos/` dengan foto milikmu. Pertahankan nama file `photo-01.jpg` sampai `photo-16.jpg`.

## Mengganti musik
Letakkan file MP3 di `assets/music/` dengan nama `tunggal-eka.mp3`.

## Upload ke GitHub
Upload `index.html` dan folder `assets` ke halaman utama (root) repository. README ini opsional. Aktifkan GitHub Pages melalui Settings → Pages → Deploy from a branch → `main` → `/(root)`.
